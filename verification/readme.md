# NIST SP 800-22 Bitstream Statistical Verification Suite

A high-performance C99 implementation of the complete **NIST SP 800-22 Rev 1a** statistical test suite (all 15 core tests), designed to ingest and validate raw or post-conditioned hardware bitstreams captured directly from FPGA Integrated Logic Analyzer (ILA) CSV data logs.

## Key Features & Capabilities
* **Full 15-Test NIST Suite (`bitstream_testing.c`):** Implements the complete set of standard randomness evaluations, including Frequency, Block Frequency, Runs, Longest Run, Binary Matrix Rank, Discrete Fourier Transform (Spectral), Non-Overlapping/Overlapping Template Matching, Maurer's Universal Statistical, Linear Complexity, Serial, Approximate Entropy, Cumulative Sums, Random Excursions, and Random Excursions Variant tests.
* **Direct FPGA ILA Log Integration (`bitstream_testing.c`):** Automatically parses multi-file CSV data exports (`iladata*_word.csv`) generated by Vivado ILA capture runs, extracting 32-bit hex words and unpacking them into a contiguous bitstream vector.
* **Embedded Mathematical Helpers (`bitstream_testing.c`):** Features self-contained implementations of statistical distribution functions—such as Lanczos Gamma approximation, regularized incomplete gamma functions (`gammaincc`), normal cumulative distribution (`erfc`-based), and a Radix-2 Fast Fourier Transform (FFT)—eliminating external math library dependencies.
* **Automated P-Value & Verdict Evaluation (`bitstream_testing.c`):** Compares observed test statistics against theoretical significance levels (`ALPHA = 0.01`), outputting formatted pass/fail validation tables directly to standard output.

* # Compiling and Running the Program
* to compile the program, run this in the terminal:
* `gcc -O3 -std=c99 bitstream_testing.c -lm -o bitstream_testing`
* and to run the program use:
* `./bitstream_testing`
